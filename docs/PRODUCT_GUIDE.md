# Thesis Backtester 功能指引

<!-- guide:intro:start -->
## 核心亮点 {#overview}

这不是一个让 Agent 自由发散的研究工具。项目以**算子 + 层级编排**为核心：算子表达可复用的研究方法，编排把多个分析方向组织成可检查、可重复执行的严肃研究流程。

## 工作逻辑 {#workflow}

维护一致的数据口径 → 选择研究模式 → 配置结构化条件 → 由确定性管线执行 → 检查结果与报告 → 由投研助手解释、补充或辅助修改。

## 三个工作区 {#workspaces}

- **基础设施**：维护数据、原生字段与派生因子、算子、研究框架和系统连接。
- **截面筛选**：管理纯数值策略，执行当前筛选并在历史截面检验前向收益。
- **结构化投研**：通过固定章节 DAG 完成个股分析、最新批量研判、严格历史框架验证与报告。
<!-- guide:intro:end -->

## 核心引擎：算子与层级编排 {#engine}

### 算子

算子是一段边界明确的研究能力，例如判断治理质量、识别估值状态或计算筛选条件。它应当说明所需数据、分析步骤、输出字段和结论边界，能够被多个研究框架重复使用。

### 层级编排

编排不是把单个算子随意拖成一条链，而是先按分析方向组合多个算子，再由章节和依赖关系组织完整研究路径。运行时严格遵循既定 DAG，保证同一输入能够沿同一路径复核。

### 投研助手的角色

助手与人工界面复用相同 API，可以解释当前状态、辅助完善算子和框架、提出结构化修改，但不会在分析运行期间动态改变研究管线。

## 一套研究怎样完成 {#research_flow}

1. 在“数据维护”中选择数据源并完成本地基线与增量维护。
2. 根据问题选择结构化投研或截面筛选。
3. 在中央页面填写结构化输入，明确股票池、时点、规则或研究框架。
4. 启动确定性执行流程，并检查每个阶段的状态、证据和输出。
5. 查看报告或回测结果，确认数据口径、时间边界和失败原因。
6. 使用投研助手解释结果或辅助修改后续研究配置，再运行新的研究。

## 基础设施 {#infrastructure}

### 数据维护

- **作用**：维护当前数据源的股票列表、交易日历、行情、复权、估值和财务数据。
- **输入**：数据源、历史起点、凭据和更新方式。
- **输出**：按数据源隔离的 SQLite 数据库及明确的覆盖状态。
- **边界**：不同数据源不会在底层自动混用；历史研究只能使用在对应时点可获得的数据。

### 因子库

- **作用**：统一查看原生字段和派生因子，并维护可复用的数值因子定义。
- **原生字段**：由 BaoStock、Tushare 等 Provider 暴露，只登记语义、单位、频率和精确度，不在因子库中改写。
- **派生因子**：通过字段选择器、常用公式模板和受限 Polars DSL 引用语义字段定义；保存前会检查表达式、依赖、输出类型和当前 Provider 兼容性。
- **自动计算**：新增或编辑后，如果当前 Provider 具备精确输入和历史指标，系统会自动排队并只重算该因子的完整历史列；失败后可以在详情中重新计算。
- **状态**：分别展示 Provider 兼容性、定义版本一致的物化状态和时点安全性；不可用字段不会从另一数据源静默补齐。
- **数据源边界**：Tushare 是完整历史财务因子的参考 Provider；BaoStock 主要覆盖行情、复权和基础估值，其季度指标不能替代完整财报。

### 算子库

- **作用**：查看、创建和维护可复用研究方法。
- **输入**：研究目标、所需数据、步骤、输出和评分规则。
- **输出**：可被研究框架引用的标准算子。
- **助手**：可以解释现有算子并生成结构化修改，修改需要用户确认后应用。

### 研究框架

- **作用**：按分析方向、章节和依赖组织多个算子。
- **输入**：章节定义、算子组合、依赖关系和综合规则。
- **输出**：可重复执行的确定性研究 DAG。
- **助手**：可以辅助检查结构和提出修改，但不会改变正在执行的任务。

### 系统设置

- **作用**：配置 LLM 连接、数据源凭据、自动更新策略和局域网访问。
- **输出**：仅保存在本机外部运行时目录的配置。
- **局域网**：默认关闭且只监听 `127.0.0.1`。开启并重启后才会监听局域网；其他设备首次访问必须输入一次性显示的访问口令。
- **权限边界**：远程用户登录后与本机用户拥有相同的研究和配置权限，只应在可信的专用网络中开启。HTTP API 与 WebSocket 使用同一会话保护，重置口令会使旧会话立即失效。

## 结构化投研 {#qualitative}

### 个股分析

- **作用**：选择股票与研究框架，沿固定章节 DAG 执行个股分析。
- **输入**：股票、框架和分析时点。
- **输出**：章节状态、算子结论、证据和最终综合判断。
- **助手**：解释进度、章节结论和异常，不取代 DAG 自由生成研究路径。

### 最新研判

- **作用**：单向引用一套已保存的数值筛选策略生成当前候选池，再用同一研究框架批量完成逐股研判。
- **输入**：筛选策略、研究框架、分析数量和并发数。
- **输出**：统一口径的综合评分、最终建议、核心逻辑、关键风险和信心水平。
- **运行纪律**：启动前展示预计任务量、时间和费用；运行时冻结候选、数据截面和框架，支持在并发批次边界暂停并继续补齐。

### 框架验证

- **作用**：在多个历史截面重复执行“数值筛选 → 固定章节 DAG → 前瞻收益”，判断研究框架是否在纯筛选池之上产生增量判断力。
- **输入**：筛选策略、研究框架、历史区间、截面频率、每期数量和并发数。
- **输出**：市场基准、筛选池等权、框架买入与框架高分组的多持有期收益和胜率，以及框架相对筛选层的增量收益。
- **历史纪律**：执行前检查每个算子的时点边界。依赖当前新闻、当前资金流或当前行业上下文的算子，会替换为输出字段和类型完全一致的历史实现；无安全等价实现时才阻止验证，不会静默跳过算子。
- **结果归属**：只展示与当前最终筛选定义、最终框架内容和当前参数一致的结果，旧内容不会冒充当前方案。

### 分析报告

- **作用**：管理个股分析和最新研判形成的正式个股报告；框架验证的聚合结果仍留在框架验证页面。
- **报告库**：通过 SQLite 索引按股票、框架、建议、来源和日期检索；JSON 与 Markdown 文件始终是事实来源。
- **阅读器**：左侧固定展示评分、建议、信心、核心逻辑、关键风险与章节目录，右侧阅读 Markdown 正文，并在底部按需展开算子证据链。
- **报告对比**：仅允许同一股票、同框架不同日期，或同一股票、同日期不同框架的两份报告，避免机械比较无关对象。
- **助手**：结合当前报告或对比上下文解释结论、变化、矛盾和数据缺口。

## 截面筛选 {#cross_section}

- **左侧工作流**：截面筛选工作区按实际任务分为“策略构建、截面选股、历史验证”三个入口，各页面拥有独立的助手上下文和对话历史。
- **策略构建**：指标库、过滤条件、加权排名、预览参数和命中结果集中在同一屏；直接组合规则即可试验，不要求先新建策略，有效规则再按需保存。
- **截面选股**：单独选择一套已保存策略、截面日期和入选数量，输出绑定策略版本、数据源、请求日期及实际交易日的股票名单，并支持导出 CSV。
- **输入**：股票池门槛、硬性过滤、多因子排名、截面区间、调仓频率和持有数量。
- **保存与验证**：策略是当前规则的可复用快照，不是进入筛选的前置步骤。历史验证页可以独立选择任意已保存策略，并按策略、日期范围、截面频率和每期入选数量组织不同回测方案；这五项共同确定结果归属，修改任一项后旧结果会隐藏，选择已有方案则会同时恢复它的完整参数。任务运行时再次冻结策略快照以保证结果可复现。
- **结果阅读**：主观察持有期自动与截面频率一致，先展示平均收益、相对基准收益与胜率；新验证同时保存逐截面收益并生成逐期复合收益曲线，再用多持有期收益图、截面入选数量图和完整统计表展开。只有已经完整走完的持有期才进入统计，未成熟期限显示为空。期限修复前的旧结果仍保留展示，并统一标记为“旧收益口径”供历史参考，无需立即重跑。已有方案按各自的策略和参数横向比较。
- **输出**：当前截面候选、可复用的筛选策略、每期入选股票、前向收益图表、方案比较、基准比较和冻结的策略快照。
- **纪律**：每个截面只能使用当时已经可获得的数据，不能引用未来财报或当前资讯。
- **边界**：这里验证的是多截面前向收益，不是包含持仓账本、交易成本、滑点和可成交性约束的组合回测。筛选策略有独立的配置源和数据库记录，不从定性分析策略或结果读取数据；结构化投研可以单向引用筛选策略或候选集，截面筛选不会反向依赖定性结果。
- **助手**：可以解释规则、辅助配置和检查口径，但不会参与每期选股计算。

## 投研助手使用边界 {#assistant}

每个功能页面拥有独立对话历史，切换页面会恢复对应上下文。助手会读取当前页面的结构化状态，并可调用与人工操作相同的现有 API。

适合交给助手的工作包括解释功能与结果、定位异常、完善研究方法、生成待确认的结构化修改。不应交给助手替代的工作包括随意改变运行中的 DAG、绕过数据时点约束或以自由对话结果代替正式研究输出。

## 使用边界 {#disclaimer}

Thesis Backtester 不包含实盘下单或自动资产管理能力。软件及其输出仅用于研究与回测，不构成任何投资建议；数据与分析可能存在误差，使用者应独立判断并自行承担风险。
