# Thesis Backtester Windows 版

## 启动

1. 将压缩包完整解压到一个可写目录，不要直接在压缩包内运行。
2. 双击 `ThesisBacktester.exe`。
3. 首次启动后，按界面指引选择数据源、下载数据并配置可选的 LLM 连接。

程序会同时启动本地服务和桌面窗口。本机浏览器也可以访问 `http://127.0.0.1:18721`。

## 文件和数据

- 所有可变研究资产统一保存在 `workspace/`：数据、框架、算子、因子、筛选策略、报告、配置和对话历史。
- 备份或迁移时完整复制 `workspace/` 即可，不要只复制其中的 `data/`。
- 如需把整个工作区放到其他磁盘，可在程序目录创建 `.env` 并设置：

```text
THESIS_BACKTESTER_WORKSPACE_DIR=D:\ThesisBacktesterWorkspace
```

- 如果只想把大型数据库移到其他磁盘，可以设置：

```text
THESIS_BACKTESTER_DATA_DIR=D:\ThesisBacktesterData
```

升级时先退出程序，将新版本解压到新目录，再复制旧版的 `workspace/`，或继续使用同一个 `THESIS_BACKTESTER_WORKSPACE_DIR`。程序内置模板仅补充缺失文件，不会覆盖工作区中的修改。

## 局域网访问

局域网访问默认关闭。只有在可信专用网络中才应从“系统设置 → 网络访问”开启。远程登录用户与本机用户拥有相同的研究和配置权限，不要将端口直接暴露到公网。

## 故障排查

- 如果桌面窗口无法创建，程序会尝试使用系统浏览器打开本地页面。
- Windows Defender 或第三方安全软件可能首次扫描新生成且未签名的 EXE；正式公开发布建议对产物进行代码签名。
- 构建信息位于 `BUILD_INFO.json`。

## 使用边界

本软件及其输出仅用于研究与回测，不构成投资建议。数据与分析可能存在误差，历史结果不代表未来表现。
